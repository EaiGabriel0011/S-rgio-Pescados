# Sérgio Pescados — Site

Site institucional responsivo, sem framework, feito com HTML + CSS + JavaScript.

## Estrutura

- `index.html` — estrutura e conteúdo
- `styles.css` — visual responsivo
- `script.js` — menu mobile, animações e WhatsApp
- `assets/hero-sergio-pescados.png` — imagem principal

## Configurar o WhatsApp

Abra `script.js` e altere:

`const WHATSAPP_NUMBER = "5500000000000";`

Coloque o número real no formato:

`55 + DDD + número`

Exemplo fictício:

`5547999999999`

## Como publicar

Você pode publicar a pasta em serviços de hospedagem estática como GitHub Pages, Netlify, Vercel ou no seu próprio servidor.

O site não usa backend e não precisa de banco de dados para funcionar.
